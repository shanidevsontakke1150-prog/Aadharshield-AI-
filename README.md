# AadhaarShield AI

AI-powered system to detect suspicious Aadhaar usage and alert citizens in real time.

## Purpose
This project is a hackathon prototype focused on preventing Aadhaar misuse, fraud, and unauthorized authentication.

## Features
- AI-based anomaly detection
- Citizen alert system
- Fraud analytics dashboard
- Privacy-first design

## Tech Stack
- Backend: Python Flask
- AI Logic: Rule-based + ML (future)
- Frontend: HTML, CSS, JS
- Database: SQLite

## Disclaimer
This is a simulation prototype. No real Aadhaar or biometric data is used.
Not affiliated with UIDAI or Government of India.
